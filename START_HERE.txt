📂 **DATA & FOLDER**

Aplikasi menyimpan data di:
C:\Users\[username]\@ Latee Library\

Subfolder:
├── library_data.db (Database SQLite)
├── qrcodes/ (Member & book QR codes)
└── laporan/ (Excel & chart exports)

═══════════════════════════════════════════════════════════════════

🎯 **TAB UTAMA APLIKASI**

1. Dashboard → Lihat statistik hari ini
2. Buku → Kelola daftar buku
3. Anggota → Daftar member + generate QR
4. Peminjaman → Proses peminjaman buku
5. Pengembalian → Proses pengembalian + denda
6. Pengunjung → Tracking pengunjung
7. Laporan → Export Excel & chart
8. Pengaturan → Kelola akun pengguna

═══════════════════════════════════════════════════════════════════

🔄 **WORKFLOW CEPAT**

Daftar Member Baru (5 menit):
  Anggota → Tambah Anggota → Isi data → Daftar → Generate QR

Peminjaman Buku (2 menit):
  Peminjaman → Scan QR Member → Pilih Buku → Pinjamkan

Pengembalian Buku (2 menit):
  Pengembalian → Masukkan NIS → Terima Pengembalian → Denda otomatis

Export Laporan Bulanan (1 menit):
  Laporan → Pilih laporan → File tersimpan ke laporan/

❓ **PERTANYAAN UMUM**

P: Bagaimana jika lupa password?
J: Tidak ada reset. Hubungi developer untuk reset database.

P: Bisakah multiple users pakai bersamaan?
J: Tidak, designed untuk single computer.

P: Apakah ada backup otomatis?
J: Tidak, silakan backup library_data.db secara manual.

P: Hardware apa yang dibutuhkan untuk fingerprint?
J: Deli ES151 (USB, baud rate 115200)

P: Apakah ada cloud sync?
J: Tidak, offline-only untuk keamanan data.
